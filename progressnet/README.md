# ProgressNet project page

Static, standalone project site for `/progressnet/` in Thecoder1012.github.io.

This package combines the approved v3 website with the final SketchX sound-update
MP4s. The page design, CSS, JavaScript, figures, comparison gallery, posters,
and paper are unchanged. The video durations have been updated in the page,
and the demo is not forced to start muted. Neither player autoplays.

Video asset filenames intentionally retain their original `150s` names for
compatibility; the branded methodology films are 157.5 seconds long.
The demo is 71.333333 seconds long. All three files have audio tracks.

No build step or server-side code is required. Keep `assets/` and `paper.pdf`
beside `index.html`. A root `.nojekyll` file is included for GitHub Pages.
The site contains no live model inference service or released model code.

Source metadata is in ASSET-SOURCES.json; checks are in QUALITY-CHECK.md.
